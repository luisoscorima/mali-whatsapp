# Documentación por dominio

Cada **concepto de producto** tiene un par:

| Archivo | Rol |
|---------|-----|
| `NOMBRE.md` | Cómo funciona **hoy** (fuente de verdad) |
| `NOMBRE-CHANGELOG.md` | Cronología, migraciones, ensayos, decisiones pasadas |

Si un changelog y un vivo chocan, **manda el vivo**.

Contrato HTTP (no es un concepto de UI): [CRM-API.md](./CRM-API.md).

Arranque local: [ARRANQUE.md](../ARRANQUE.md). Producción: [DESPLIEGUE.md](../DESPLIEGUE.md). Overview: [README](../README.md).

Los `*-CHANGELOG.md` son evidencia breve (no runbooks). Si chocan con el vivo, manda el vivo.
